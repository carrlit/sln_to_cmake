# MSVC solution to CMake Converter

This Python script converts **Microsoft Visual Studio solutions (`.sln`)** and individual projects (`.vcxproj`) into **CMakeLists.txt** files. It generates:

- A root `CMakeLists.txt` for the solution
- `CMakeLists.txt` for each project

It automatically handles:

- `.cpp`, `.c`, `.h`, `.hpp` source and header files
- Qt-specific files: `.ui`, `.qrc`, `.h` (for QtMoc, QtUic, QtRcc)
- `.rc` resources and image files
- Additional include directories and preprocessor definitions
- Libraries (`.lib`), filtering out system Windows libs and converting Qt libs to `Qt${QT_VERSION_MAJOR}::Module`
- Project dependencies
- Project filters for IDE integration

It works for Qt6 projects and supports `.vcxproj` files generated by Visual Studio 2019, 2022, and newer.

---

## Features

- Generates a `CMakeLists.txt` for each project and a root `CMakeLists.txt` for the solution
- Supports **Qt modules** defined in `<QtModules>` or libraries
- Correctly handles debug libraries (`Qt6Cored.lib`) and replaces them with modern CMake targets (`Qt6::Core`)
- Automatic handling of `AUTOMOC`, `AUTOUIC`, `AUTORCC`
- Cross-project dependencies are automatically added via `target_link_libraries`
- Supports both static and shared libraries

---

## Requirements

- Python 3.10+
- Windows with MSVC solution/projects (tested with VS2019/2022)
- CMake 3.20+ for generated files

---

## Installation

Clone the repository:

```bash
git clone https://github.com/carrlit/sln_to_cmake.git
cd sln_to_cmake
```

No installation is needed. The script is pure Python.

---

## Usage

### Convert a solution in the current directory

```bash
python sln_to_cmake.py
```

Generates:

- `CMakeLists.txt` for each project in the solution
- A root `CMakeLists.txt` in the solution directory

---

### Convert a specific solution

```bash
python sln_to_cmake.py "C:\Projects\MySolution\MySolution.sln"
```

### Convert using a directory (first `.sln` found inside)

```bash
python sln_to_cmake.py "C:\Projects\MySolution"
```

---

### Examples of Generated CMake

**Root solution `CMakeLists.txt`:**
```cmake
cmake_minimum_required(VERSION 3.20)
project(MySolution)
message(STATUS "Prepare: ${PROJECT_NAME}")

set(CMAKE_CXX_STANDARD 20)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

set(CMAKE_AUTOMOC ON)
set(CMAKE_AUTOUIC ON)
set(CMAKE_AUTORCC ON)

add_subdirectory(ProjectA)
add_subdirectory(ProjectB)
```

**Individual project `CMakeLists.txt` (`ProjectA`):**
```cmake
project(ProjectA)
message(STATUS "Prepare: ${PROJECT_NAME}")

set(SOURCE_FILES
    src/main.cpp
    src/foo.cpp
)

set(HEADER_FILES
    include/foo.h
)

set(UI_FILES
    forms/mainwindow.ui
)

set(QM_FILES
    resources/resources.qrc
)

add_executable(${PROJECT_NAME}
    ${SOURCE_FILES}
    ${HEADER_FILES}
    ${UI_FILES}
    ${QM_FILES}
)

target_link_libraries(${PROJECT_NAME}
    Qt${QT_VERSION_MAJOR}::Core
    Qt${QT_VERSION_MAJOR}::Widgets
)
```

- All source, header, UI, QRC, resource, and image files are automatically added.
- Dependencies between projects are linked automatically.

---

## Notes

- System Windows libraries (e.g., `kernel32`, `user32`) are skipped automatically.
- Debug suffixes (`d`) in Qt libraries are handled correctly.
- For Qt projects, the script detects `.ui`, `.qrc`, and `<QtModules>` entries.
- The script does not modify the original Visual Studio solution or projects.
